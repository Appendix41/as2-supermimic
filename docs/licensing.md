The author has requested publication, but the license and copyright attribution
for new contributions, locally generated reference data, checkpoints, and demo
media have not yet been confirmed. This release candidate does not silently
assign a blanket MIT license.

The initial GitHub upload is a private staging repository under `Appendix41`,
with a draft model release. Account ownership and Git commit attribution do not
replace the pending copyright and licensing decision.

Existing third-party notices and license texts are preserved:

- Go2-SuperMimic-derived baseline code: MIT, Ziyue Zheng.
- Official Unitree AS2 assets/configuration evidence: Apache-2.0, with the
  original license retained under each baseline's `third_party/`.

The unused Kine2Go external motion dataset is not redistributed here.

Before public release, confirm the author's name and applicable licenses,
add the appropriate top-level LICENSE, and keep all required third-party
notices. The later hardware controller and runtime snapshot have now been
imported, but their new contributions still require the author's attribution
and publication-rights confirmation. SDK source, vendor shared libraries, and
virtual environments were not copied into the release.
